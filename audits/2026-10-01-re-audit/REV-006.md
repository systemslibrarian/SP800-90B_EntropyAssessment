## Readable-file digest fault injection — explicitly artificial

Archived checkpoint-6 injection source is unavailable. A new independent LD_PRELOAD shim intercepts **EVP_DigestInit_ex**, prints a unique proof marker on each injected call, and returns 0. With injection disabled it forwards to the real OpenSSL function. This is **not a naturally occurring production failure**.

Public positive-control input: truerand_8bit, 1,000,000 byte samples, alphabet 0–255, declared width 8, MSB-first bit expansion, SHA-256 `c7e56911d2657fa9b6e86c03d4477474d6ec698691c5f32d3918ec513713e3c3`. No private data was used or exposed. The full original algorithm/simulation coverage is retained; no rounds were reduced.

| Build / shim state | ea_non_iid | ea_iid | ea_restart -n |
|---|---|---|---|
| Fixed, pass-through control | exit 0; true hash; assessment | exit 0; true hash; full IID assessment | exit 0; true hash; validation passes |
| Fixed, injected digest initialization failure | exit 255; errorLevel=-1; no hash; no test cases/assessment | same | same |
| Ignored-status mutant, same injection | exit 0; errorLevel=0; assessment continues | same | same; validation passes |
| Actual restart repair parent, same injection | not tested in this row | not tested in this row | exit 0; errorLevel=0; garbage hash; full assessment/validation continues |

Each injected run has **exactly one shim proof marker AND the real helper's “Can't setup mdctx as a SHA256 context.” diagnostic**. This establishes that a readable file reached digest initialization, that it failed deliberately, and that the error propagated to the helper before the caller either rejected or ignored it. Parent/control/mutant runs all completed within their individual budgets (longest 111.477 s). JSON and complete stdout/stderr are preserved; hash_results_analysis.py checks all outcomes, not merely grep absence.

## Verdict

Repair correctness is supported for the tested injected failure across all three built programs. The actual restart pre-fix failure is demonstrated on the appropriate immediate parent, with passing repaired controls and compiling/reachable ignored-status mutants exposed by the independent injection checks. The claimed original regressions **do not** detect all ignored-status defects. Their verification claim is **OVERSTATED**, not evidence that the implemented repair is incorrect.

Overall prior finding: **PARTIALLY SUPPORTED**, because core sensitivity/coverage and injection behavior are confirmed, while the claimed immediate-parent original-regression PASS did not reproduce locally and exact archived scripts are unavailable. Conditioning's fourth instance was not tested and is not claimed fixed.
