# MANIFEST — novel-findings

Every committed file in this directory, with its source, SHA-256 and what it supports.

## Regeneration and exclusions

Generated `.bin` inputs are not committed. Each finding section of `REPORT.md` contains inline generators, and the scripts under `generators/` rebuild the rest. For example:

`python3 generators/noniid/f09gen.py 3 300 f09b.bin` rebuilds F09's input; verified byte-identical: SHA-256 `1e2ae594015da8b51094790159d9e380b4d12b30e4eb9c708c4cd8dc90b1c534`.

Binaries: build upstream `87c104d` with its Makefile (see `logs/build-rel.log`, `logs/build-asan.log`).

Original layout: the "Original path" column is relative to the audit session's scratchpad (`SCRATCH` = the session's temporary directory). To re-run a harness in its original layout, copy files back to those relative paths. Absolute `/tmp/...` paths that appear inside preserved logs and scripts refer to that original workspace; they were left unedited so the evidence is unaltered.

Not committed:

- `FINAL-REPORT.md`: the pre-commit draft, differing only in a paragraph of scratch paths.

- `work/exclusion-map/*.txt`: derived from raw issue/PR dumps that can be re-fetched.

- `sp800-90b.txt` copies: regenerate from the official PDF.

- the `#271` API response `posted.json`: re-fetchable.

- `.done` marker files.

- all binaries, build trees, dependency directories and `.bin`/`.col` data (see the parent README).
