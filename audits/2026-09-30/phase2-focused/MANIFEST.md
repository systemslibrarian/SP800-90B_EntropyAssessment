Original layout: `SCRATCH2` = the phase-2 session's temporary directory; `TASKS2` = its background-task output directory.

- packaging archives and file lists;

- the raw issue/PR snapshot (re-fetchable with `gh`);

- the `#272` API JSON (re-fetchable).
