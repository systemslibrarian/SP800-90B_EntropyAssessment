Spec: SP 800-90B 3.1.5.2 (PDF p. 25): "Let the obtained entropy estimate per bit
be h'. The output of the conditioning component (nout) shall be treated as a
binary string, for purposes of the entropy estimation. ...
h_out = min(Output_Entropy(n_in, n_out, nw, h_in), 0.999 n_out, h' x n_out)."

The only unit the standard defines for the conditioned dataset is PER BIT.
The multiplication by n_out belongs to h_out and uses the conditioner's output
width, which this tool does not know. Nothing in 3.1.5.2 multiplies h' by the
packing width of the file.

Correct report for `ea_non_iid -c ... file 8`:
  stdout        h': <v>                  (per bit; this is what the tool prints)
  JSON          either hAssessed == <v> (per bit, matching the text), or a field
                that names the unit / the mode (e.g. "hAssessedUnit": "per 8-bit
                packed symbol" or "hPrime": <v>).
