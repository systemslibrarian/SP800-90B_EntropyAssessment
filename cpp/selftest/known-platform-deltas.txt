# Known platform deltas (upstream #155), as an EXPECTED-RESULT MANIFEST.
#
# WHY THIS REPLACED A FILENAME LIST (A06 / OC-56).
#
# --allow-known-platform-deltas used to excuse any mismatch whose FILENAME was
# one of two names, without inspecting the estimator, the field, the magnitude,
# the direction or the platform. An isolated controller fed it a deliberate
# change from 0.85 to 0.01 in one of those files and it was accepted. A guard
# that cannot tell a 1e-10 last-digit platform difference from a 0.84 collapse
# is not guarding.
#
# FORMAT
#   platform <uname-s> <uname-m> <compiler-substring>
#       ... one or more delta rows, each:
#   delta <file>|<estimator>|<field>|<max-abs-delta>|<observed-magnitude>
#
# THE OBSERVED MAGNITUDE IS THE FIFTH FIELD, AND IT IS NOT DECORATION (OC-87).
# Every row carried the same uniform tolerance, 1e-9, which concealed that the
# headroom is 2.7x on one row and 8.0x on another: the observed deltas run from
# 1.25e-10 to 3.66e-10. A tolerance whose headroom is not printed is a tolerance
# nobody checks, and this is the third time this round that slack has defeated
# detection -- after a floor of 9 against a count of 10, and a flat 1% against
# values recorded to three significant figures.
#
# So each row now carries what was MEASURED beside what is ALLOWED, and
# check-platform-deltas.py prints the ratio. The tolerance is unchanged: this
# round makes the slack auditable, it does not retune it, because the smallest
# REAL defect in these cells has never been measured and retuning without that
# number would be swapping one unjustified figure for another.
#
# WHAT THE UNESTABLISHED LIMB ACTUALLY IS. The tolerated 1e-9 is the same order
# of magnitude as C22a (8.08e-9 bit at n = 1e6), the floor's own quantisation
# term. So a difference this manifest excuses cannot be dismissed as negligible
# by comparison with the corrections the floor already makes -- the two are the
# same size. Whether it can reach a published figure depends on whether a
# prediction estimator ever binds for these files, which is NOT ESTABLISHED.
#
# A failing selftest is excused ONLY when, for the platform actually running:
#   1. a `platform` block matches this host (uname -s, uname -m, and the
#      compiler identity substring) -- otherwise the exception does not apply
#      at all, however familiar the filenames;
#   2. EVERY reported difference matches a `delta` row exactly on file,
#      estimator and field, and its |delta| is within that row's tolerance;
#   3. EVERY `delta` row listed for this platform was actually observed -- a
#      comparison that silently stopped happening must not pass as an absence
#      of difference.
#
# TOLERANCES ARE MEASURED MAGNITUDES WITH HEADROOM, NOT BOUNDS, and are
# labelled as such because an observed maximum is not a bound (rule 6). The
# observed deltas here are 1.25e-10 to 3.66e-10 on quantities of order 0.04 to
# 0.97; 1e-9 leaves roughly 3x headroom while failing anything larger by orders
# of magnitude. If a delta ever exceeds its row, that is a finding and the row
# must not simply be widened to swallow it.
